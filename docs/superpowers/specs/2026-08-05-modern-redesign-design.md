# 겜스고 디자인 시스템 모던 리디자인

## 배경

겜스고 사이트는 Next.js 16 + Tailwind v4 기반 AI/OTT 구독 할인 비교·리뷰 사이트다. 현재 디자인은 흰 배경 + 로즈레드(#EF534F) 포인트 컬러 + 얇은 보더 카드 위주로, 기능적이지만 그라데이션·깊이감·타이포 대비가 거의 없어 "예쁘다"는 인상이 약하다. 이번 작업은 Figma 등 외부 디자인 툴 없이, 코드 베이스 안에서 바로 디자인 시스템을 다듬는 것을 목표로 한다.

**참고 무드**: 토스(Toss) 스타일 미니멀 — 색을 아끼고 흰/회색 위주 바탕에 브랜드 컬러는 "행동을 유도하는 지점"에만 절제해서 사용, 넉넉한 여백, 그림자 기반 카드.

**범위**: 전체 디자인 시스템(컬러 토큰, 카드 스타일, 타이포/여백)을 `globals.css`와 공통 컴포넌트(Header, Footer, AffiliateCTA, ServicePriceCards 등)에 적용한 뒤 홈페이지에서 검증하고, 나머지 서브페이지는 같은 컴포넌트/유틸을 재사용하므로 자동으로 반영된다. 서브페이지별로 눈으로 훑어보며 어색한 부분만 미세 조정한다.

## 1. 컬러 시스템

- **배경**: 섹션이 얹히는 바탕에 `neutral-50`(아주 옅은 회백색)을 깔아 흰 카드가 배경 위에 떠 있는 느낌을 준다. 본문(`body`) 배경 자체는 흰색 유지.
- **텍스트**: 헤드라인 `neutral-900`(기존과 동일), 본문 텍스트는 `neutral-500` → `neutral-600`으로 살짝 진하게(가독성 개선).
- **로즈(브랜드 레드, `--color-rose-*`, #EF534F 스케일)**: 큰 색 블록으로 채우는 용도를 최소화하고, CTA 버튼·가격 숫자·활성 네비/hover 상태 등 "행동을 유도하는 지점"에만 사용한다. 기존 rose 팔레트 값(50~950)은 그대로 유지, 사용 위치만 절제한다.
- **민트/그린 태그**(`제일 무난`, `검색 특화` 등 파스텬 칩): 현재 스타일 그대로 유지. 이미 토스식 파스텔 칩 패턴과 맞다.

## 2. 카드 시스템 (공통 카드 스타일)

일반 카드(가이드 링크 카드, 리뷰 피드 카드 등 `border border-neutral-200` 기반 카드)에 적용:

- 보더 제거(또는 매우 옅게), 대신 다층 그림자로 입체감을 준다: 기준값 `0 1px 2px rgba(0,0,0,.04), 0 8px 24px rgba(0,0,0,.06)` 정도의 은은한 float 그림자.
- 반지름은 `rounded-xl`/`rounded-3xl` 혼용 중인 걸 `rounded-2xl`로 통일(가격 카드 등 기존에 의도적으로 다른 radius를 쓰는 곳은 예외).
- hover 시 기존 `-translate-y` 유지, 그림자만 더 퍼지도록 강화(예: hover 시 블러/확산 반경 증가).
- Tailwind v4 `@theme`에 재사용 가능한 그림자 유틸(예: `shadow-float`, `shadow-float-hover`)을 정의해서 여러 컴포넌트에서 공유한다.

## 3. 가격 카드 (`ServicePriceCards`) — A안: 배지 유지 + 톤만 다듬기

`ServicePriceCard`의 로즈레드 웨이브 배지(하단 코랄 곡선)는 실제 겜스고 결제 페이지 카드 디자인과 통일감을 위해 최근에 의도적으로 만든 것이므로 유지한다. 단:

- 채도/톤을 조금 더 부드럽게 다듬는다(예: 그림자를 부드럽게, 곡선 처리를 더 매끈하게).
- 카드 전체를 감싸는 흰 상단부에는 위 "카드 시스템" 규칙(보더 제거 + 그림자)을 적용해 나머지 카드들과 톤을 맞춘다.
- 하단 웨이브의 로즈 블록 자체(가격 강조 배지)는 색과 형태를 유지 — 실제 상품 카드와의 시각적 연결점을 해치지 않는다.

## 4. 타이포그래피 & 여백

- 홈페이지 h1: `text-2xl` → `text-3xl md:text-4xl`로 키우고 자간을 살짝 좁힌다.
- 섹션 간 간격: `gap-8` → `gap-10`~`gap-12`로 넉넉하게.
- 카드 내부 패딩도 전반적으로 한 단계씩 늘려 여백을 확보한다.

## 5. 헤더 / Footer / CTA

- **Header**: 로고 + 우측 내비 + 키워드 스크롤 칩 구조는 이미 토스식이므로 구조 변경 없음. sticky 상태에서 그림자/블러 정도만 다듬는다.
- **Footer**: 구조 변경 없음, 새 여백 스케일에 맞춰 패딩만 조정.
- **AffiliateCTA**: 현재 스타일(로즈 솔리드 배경 + hover lift + shadow-rose-200)이 이미 방향과 맞으므로 유지하되, 그림자 값을 새 카드 시스템 톤(더 부드러운 확산)에 맞춰 미세 조정한다.

## 6. 적용 순서 / 검증 방법

1. `app/globals.css`에 새 토큰·유틸(카드 그림자, 여백 스케일 등) 정의.
2. 공통 컴포넌트(`Header`, `Footer`, `AffiliateCTA`, `ServicePriceCards`)에 적용.
3. `app/page.tsx`(홈페이지)에서 전체적으로 `npm run dev`로 띄워 실제 브라우저로 검증.
4. 나머지 서브페이지(`ai-subscription-discount`, `netflix-discount` 등)는 같은 컴포넌트/유틸을 재사용하므로 자동 반영되며, 페이지별로 스크린샷/브라우저 확인으로 어색한 부분만 미세 조정.
5. 기존 기능(링크, 폼, 애니메이션)에 회귀가 없는지 확인 — 순수 스타일 변경이므로 별도 테스트 코드 추가는 필요 없음.

## 비범위 (이번 작업에서 하지 않는 것)

- Figma 등 외부 디자인 툴 연동(Figma MCP 등) — 코드 내에서 직접 스타일링.
- 정보 구조/카피 변경, 새 섹션·페이지 추가.
- 가격 카드의 웨이브 배지 형태 자체를 없애는 것(B안은 채택하지 않음).
